# Venture.ai - Travel Planning Engine

## Vertical: AI-Powered Travel Assistant
Venture.ai is designed as a smart, dynamic travel assistant that simplifies the planning process by synthesizing user preferences, budget constraints, and local data into a cohesive journey.

## Approach & Logic
Our approach uses **Synthesized Intelligence**. Instead of just searching, the engine evaluates:
- **Travel Style Weights**: Matches activities to user personas (Adventure, Luxury, etc.).
- **Budget Intelligence**: Real-time calculation of costs against user limits.
- **Contextual Simulation**: A live network feed simulates real-world constraints like weather and flight availability.

## How it Works
1. **Input Collection**: Users define destination, dates, budget, and style.
2. **Analysis Engine**: The logic filters a master dataset of destinations and activities.
3. **Itinerary Generation**: A multi-day schedule is built using weighted randomization to ensure variety and style alignment.
4. **Optimization**: The cost engine dynamically calculates totals and provides "Cost Intelligence" insights.

## Assumptions
- **Data Source**: Current data is mock-synthesized to demonstrate the engine's logic. In a production environment, this would be replaced by live feeds from Google Places and Maps APIs.
- **Currency**: All calculations are currently in INR for regional consistency.
